# spex install-cli

Install the `spex` CLI tool to `~/.local/bin` via symlink.

## Usage

```text
/spex install-cli
```

## Procedure

Follow these steps in order. Do not skip or reorder.

### Step 1: Run Install Script

Run:

```bash
$spex_skill_dir/scripts/spex install-cli
```

Report the output to the user.
